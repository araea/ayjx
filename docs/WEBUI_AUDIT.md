# Web UI 审计与改进记录（2026-09-09）

审计范围：内嵌页面、Web UI JSON 接口、表单推导、HTTP 请求解析，以及通过 ctl 的配置保存链路。

| 发现 | 修复 |
| --- | --- |
| 保存回执重画整张表单，连续编辑会失焦并覆盖尚未提交文本 | 分离服务端状态与内存草稿；正在编辑时保留原控件，写入串行排队 |
| 写入失败仅短暂提示，开关可能停留在错误状态 | 字段内错误、底部状态及重试入口；开关按服务端已确认状态显示 |
| 原始 TOML、输入中的标签切换页面后丢失 | 草稿按插件和配置路径保留；离开页面提示；敏感草稿不持久化 |
| 中文输入过程中可能提交未完成文字 | 使用标准 composition 事件监听，组合输入期间暂停自动保存和快捷键 |
| 数组小数被截断、布尔值作为字符串、正文被空格拆开 | 严格整数校验、正确布尔类型、字符串整段添加 |
| 前端 TOML 拼接可能将根键写入前一个子表，或丢失数字类型/精度 | 服务端返回原生 TOML 文本，并做往返回归验证 |
| 父级表的 JSON 值可能重新暴露子级敏感键 | 所有表和数组递归隐藏；含敏感键的 raw 字段不返回原文 |
| 全插件恢复默认会清空面板凭据 | Web UI 重置保留当前密钥；禁止通过面板清空/重置为空密钥；轮换后更新当前会话 |
| 字段与指纹逐次读取，可能拼出不一致状态 | 整个状态响应使用同一份配置快照；前端丢弃跨写入的旧轮询响应 |
| 嵌套筛选仅过滤顶层、侧栏按钮嵌套、触屏控件过小 | 递归筛选、独立导航按钮与开关、触屏布局与可访问名称 |
| HTTP 可接受非法/重复长度、截断请求体，头部边界检查不完整 | 拒绝不支持的传输编码和歧义长度，完整检查头部/请求体，禁止 iframe 嵌入 |

保存继续复用 ctl 的类型和语义校验、管理入口保护、保存锁与原子写盘；不引入另一套配置文件或前端依赖。

## 已知边界

- 「全部保存」逐项提交，不是多个字段一起成功或一起回滚。不同浏览器/聊天端同时改同一字段，最后成功写入者生效。
- 草稿只保存在当前页面内存。浏览器重载、被系统回收后不会恢复；普通字段自动保存，复杂文本需要明确保存。
- 面板管理插件自己的配置；顶层连接、全局过滤以及 oai 独立数据库配置仍沿用原管理入口。
- 仍采用原有密钥访问模式和本机 HTTP 监听；跨设备访问沿用文档中的 TLS 反向代理方式。
- 本仓库没有 GitHub Actions 部署流水线，部署产物是内嵌页面的 Rust release 程序，由本机 bot/tmux 管理。

验证命令及浏览器环境见 [网页面板](WEBUI.md#验证)。
