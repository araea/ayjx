# 网页面板 webui

`ctl` 在聊天里管配置，`webui` 把同一套能力搬到浏览器里：左边一列插件，
右边一张按插件真实配置生成的表单。普通字段停笔 800 毫秒后自动保存，
密钥和 TOML 有明确的保存按钮；底部始终显示连接与保存状态。

面板不是第二套配置系统——每一次写入最终都走 `ctl` 的同一条事务：同样的类型
校验、同样的保命规则（不能关掉 ctl、不能锁死管理入口）、同样的「先写盘再改内存」。
两边的回执也是同一句话，不会出现「网页上成功、聊天里失败」。

## 打开

首次启动会随机生成密钥写进 `config.toml`，并在日志里打出带密钥的完整地址：

```
[INFO] [Plugin/WebUI] 网页面板已就绪：http://127.0.0.1:6520/?k=<密钥>
```

也可以在**私聊或本机控制台**发送 `/webui` 取回这条链接（群里不给，密钥不该出现在群消息里）。
浏览器打开一次后密钥记在本地，之后直接访问首页即可。

| 指令 | 功能 |
| --- | --- |
| `/webui`（别名 `面板`、`网页面板`） | 取回带密钥的地址；仅限私聊或控制台，且需 `ctl.admins` |
| `/webui 状态` | 监听地址与运行状态，对所有人可见，不含密钥 |
| `/webui 重置密钥` | 生成新密钥，旧链接立即失效 |

## 配置

```toml
[webui]
enabled = true
bind = "127.0.0.1"   # 只监听本机
port = 6520
token = "…"          # 首次启动自动生成
public_url = ""      # 走反向代理或要用局域网 IP 打开时填
```

监听地址、端口与启用状态需要重启后完整生效（监听在启动时建立）。
密钥保存后立即生效，当前页面同步更新凭据；整插件恢复默认保留当前密钥。
端口被占用时面板不启动，
日志里会写明原因，机器人本身照常运行。

## 安全边界

**只有一道：密钥。** 拿到密钥的人以维护者身份操作，与本机控制台等同——
可以改任何插件的任何配置。默认 `bind = "127.0.0.1"` 意味着只有这台机器上的
程序连得上；改成 `0.0.0.0` 就是把这份权限交给整个局域网，日志会为此单独告警。
面板走的是明文 HTTP，要跨机器访问请自己套一层 TLS 反代，并把 `public_url`
指向反代地址。

密钥不出进程：`/api/state` 里所有名字含 `token`、`secret`、`password`、`api_key`
之类的字段一律以 `null` 返回，页面只显示「已设置 / 未设置」。要改这类字段就
直接填新值并点击「保存密钥」，留空表示保持不变。嵌套表和数组也递归隐藏
敏感键；含敏感键的自定义 TOML 整体隐藏，避免显示占位符后误保存覆盖真实凭据。

## 表单是怎么来的

没有第二份「配置模式」文件——表单从插件的**默认配置**推导：

- 布尔值 → 开关，点一下即存；
- 数字 → 带数字键盘的输入框，停笔 800 毫秒、回车或失焦提交，`Esc` 撤销；
  小数不会被偷偷截断成整数，非法输入保留原文并显示字段错误；
- 字符串 → 文本框；取值固定的（如 `ai_news.card_theme`）→ 下拉框，
  候选来自 `ctl::options`，与校验读同一张表；长文本使用多行编辑器；
- 数组 → 标签编辑器，回车、失焦或点击「添加」提交，点击标签上的删除按钮移除；
  数字支持逗号或空白分隔批量粘贴，字符串整段作为一项，保留正文中的空格与逗号；
- 键由用户自定的表（如 `ai_news.group_preferences`）→ TOML 文本框，写法与 `/ctl set` 一致。

默认值为空数组时元素类型无从得知，面板会拿一个试探元素去问插件自己的
`validate_config`：谁不报错就是谁。答案永远和运行时的真实类型一致。

每一项旁边写着默认值，改动过的项标出来并给一个「恢复默认」；插件页底部另有
「恢复该插件全部默认值」（保留开关、`ctl.admins` 与面板访问密钥）。

## 编辑与保存

- 页面内的写入按顺序提交，等服务端确认写盘后才显示「已保存」。连续输入时不重建
  正在编辑的输入框，保留焦点、光标、输入法组合状态和浏览器撤销历史。
- `Ctrl+S` / `⌘+S` 或底部「立即保存」提交当前页面全部待保存草稿，包括其他插件
  的草稿；每一项独立走原子保存，**不是跨字段的整体事务**。
- 密钥与自定义 TOML 需要点击保存或使用上述快捷键。TOML 由服务端原生序列化，
  保留根键/子表归属、浮点类型与大整数；输入不合法时保留文本供修改。
- 保存失败会在对应字段显示原因，侧栏标出该插件待保存数量，底部提供「重试保存」。
  请求超时代表结果尚未确认，草稿继续保留；重试将同一个字段设为用户指定的值。
- 草稿在本页内存中保留，切换插件、切换标签、筛选、同步或点击刷新状态均不丢失。
  它们不会写入浏览器持久存储；关闭/重载页面时，未保存项触发浏览器离开提示。
  移动系统强制终止浏览器可能无法触发提示，因此请以底部「已保存」为准。
- 普通文本/数字框内按 `Esc` 恢复已保存值；密钥、TOML 和数组支持「撤销草稿」。
  已经发出的保存请求不能撤销，需在保存完成后改回原值。
- 搜索支持插件名、指令、配置路径与中文字段名；详情可筛选嵌套配置或只看已改项。
  手机通过「插件列表」返回，桌面保留双栏；首次主题跟随系统，手动选择会记住。
  系统减少动态效果时关闭过渡动画，表单和保存状态提供辅助技术标签。

## 与聊天端并存

面板每 4 秒比一次配置指纹，聊天里用 `/ctl` 改的东西几秒内自己出现在页面上；
正在输入时不打断。断网时底部显示连接中断，恢复连接后继续同步，失败草稿由用户重试。反过来，面板的改动也立刻对聊天生效，规则与 `/ctl` 相同：
消息开关下一条消息生效，首次启用与定时排期需要重启。

## 实现

- 服务端：`src/plugins/webui/server.rs`，直接在 tokio 上解析 HTTP/1.1，
  不引入 web 框架。请求头 16 KiB、body 256 KiB、单次会话 20 秒，全部写死。
- 接口：`src/plugins/webui/api.rs`，`GET /api/version`、`GET /api/state`、
  `POST /api/command`（`toggle` / `set` / `reset`）。
- 表单推导：`src/plugins/webui/schema.rs`。
- 页面：`res/webui/index.html`，整页内联、零外部资源——这台机器随时可能没有网。

## 验证

```sh
cargo test
cargo build --release
node tests/webui.cjs
```

浏览器回归需要 Chromium 与支持全局 `WebSocket` 的 Node.js（建议 22+），不需要 npm 依赖。
可设置 `CHROME_BIN` 指定可执行文件，或用 `CDP_URL` 指向已运行的测试浏览器调试地址；
设置 `WEBUI_ARTIFACTS` 可保留桌面/手机截图。测试自动创建隔离配置和数据库，关闭业务插件，
覆盖 HTTP 鉴权与落盘、连续保存、失败重试、数组、草稿、中文输入法、密钥轮换及移动布局，
不会使用真实 Satori 连接。
