# 群聊搭话

`oai` 的可选能力：让本机 pi 以固定人格作为 QQ 群友参与聊天。默认关闭，
只在 `[oai.ambient].groups` 列出的群里生效。

## 参与方式

群消息先进入每群 80 条的内存窗口，安静 3 秒后交给判定模型，持续刷屏时最多等 12 秒。
判定与发言读取同一份实际人设，并看到最近发言时间、频率与当前关注的话题。
判定输出 `{"score":60,"reason":"接得上梗","continuation":false}`；
分数过线才唤起人格模型，被 @ 或引用近期机器人消息时可直接交给人格。

人格始终有最后决定权，**包括被 @ 时也可以只输出 `[silent]`**。
没有兴趣、话题结束、别人已经答过时可以旁观；不因很久没说话而强行刷存在感。
默认不设硬冷却和每小时发言配额，也不随沉默时长降低门槛。
管理员仍可显式开启这些旧参数，既有配置里的非零值会保留。

人设选择跟进时，可输出内部状态行：

```text
[focus:{"users":[114514],"topic":"刚聊的游戏机制","seconds":180}]
这下全自动坐牢了
```

最多关注三位当前记录里的群友，也可以 `users:[]` 只跟话题。
默认一次最多 300 秒，可以随互动续期；`[focus:{"seconds":0}]` 主动结束。
省略则保持原关注直到到期，也可与 `[silent]` 同时使用，表示先看着。
关注期间防抖缩短至 1 秒；判定确认新消息仍在延续互动且分数非零时，
可绕过普通分数门槛与可选冷却，再让人格决定是否说话。
同一个人换了无关话题不算续聊，新群友接上原话题则可以。

关注不会启动定时发言，没有新群消息就不会自己接自己。上下文和关注均不落库，重启清空。

## 消息续接与新鲜度

- 每群只有一个 worker。模型执行或分条发送期间收到的新消息，会自动合并为下一批处理。
- @ 按批次消费，人格拒绝回应后不会用旧 @ 一再强制唤醒。指令不进入聊天窗口。
- 判定完成后重新读取最新记录再生成。生成期间又有消息时，先让判定模型检查草稿是否仍然合适：
  补充和同话题闲聊不必重写；问题已解决、被纠正或转移话题则收起草稿重新判断。
  检查期间再有新消息也会让位给下一批，极密集刷屏时仍可能暂时保持沉默。
- 分条发送时若有新消息或管理员停用插件/移除群，停止尚未发送的部分。
- 只有成功发送才计入发言频率；保存消息回执用于识别引用与去重。

## 表达和输出

人格的性格是底色，实际表达是群友在手机上打字：口语、碎句、接梗、适度抽象与自嘲，
不把每次搭话写成文学独白或纠错点评。通常省略句末标点；问号、省略号等语气标点可保留，
偶尔较长消息像语音转写一样带标点也正常。此习惯由提示词引导，不对正文机械删标点。

一行一条消息，默认最多 3 条；通常每条不超过 30 字。
行内支持 `[at:QQ号]`、`[face:表情ID]`、`[img:直链]`；独占一行支持
`[poke:QQ号]`、`[dice]`、`[rps]`、`[wait:秒数]`、`[silent]`。
`[reply]` 前缀引用生成时记录里最后一条群友消息。
`[focus:…]` 属于内部控制行，解析失败也不会发到群里；其余未知方括号保留原文。

模型耗时计入首条的思考和打字等待，避免生成完再额外等十几秒。
后续条目按打字速度错开发送，长句按语音输入速度折算，随机浮动并保留约 1 秒换气。

完整消息协议在 `res/ambient/skills/satori-reply/SKILL.md`，每次启动同步到
`data/oai/ambient/skills/satori-reply/SKILL.md`。

## 人设和升级

`res/ambient/persona.md` 是仓库默认人设。首次启动写到 `data/oai/ambient/persona.md`，
**之后不自动覆盖**，判定和发言每轮读取磁盘版本。
升级已运行实例时，需要将群聊场景与口吻调整同步到实际数据目录的人设，保留原有人格定制；
只更新仓库文件不会替换线上人设。想恢复默认版本可删除运行时人设后重启。

从旧配置升级，若希望由人格自主控制节奏，将 `cooldown_seconds`、`hourly_limit`、
`silence_relief_per_10min`、`silence_relief_cap` 设为 `0`，
`debounce_seconds = 3`、`max_wait_seconds = 12`、`focus_max_seconds = 300`。
运行中通过本机控制台 `/ctl set oai ambient.字段 值` 修改；手工编辑配置前先停止 bot，
避免退出时的自动保存覆盖修改。

## 配置

`config.toml` 的 `[oai.ambient]`：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `false` | 总开关 |
| `groups` | `[]` | 允许搭话的群号 |
| `gate_model` | `gemini-3.5-flash-lite` | 判定模型，复用 oai 接口与密钥 |
| `reply_model` | `apilio/gemini-3.8-flash` | pi 的发言模型 |
| `thinking` | `low` | 发言模型思考强度 |
| `tools` | `read,bash,web_search,fetch_content,get_search_content` | 工具白名单 |
| `score_threshold` | `45` | 普通开口意愿门槛，调高更沉默 |
| `focus_max_seconds` | `300` | 每次关注期限上限，最多 600 秒；0 关闭 |
| `silence_relief_per_10min` | `0` | 可选：每沉默 10 分钟降低的门槛分数 |
| `silence_relief_cap` | `0` | 可选：门槛降低上限 |
| `context_turns` | `20` | 最近消息数，限制在 1–80 |
| `context_images` | `2` | 最新图片数；0 关闭 |
| `debounce_seconds` | `3` | 普通消息合并等待；关注时至多 1 秒 |
| `max_wait_seconds` | `12` | 持续有消息时最多等待时间 |
| `cooldown_seconds` | `0` | 可选硬冷却；点名或关注续聊绕过 |
| `hourly_limit` | `0` | 可选每群每小时发言轮数上限；0 不限 |
| `reply_on_mention` | `true` | 新 @ / 引用跳过筛选，但人格仍可沉默 |
| `max_messages` | `3` | 一轮最多条数，限制在 1–5 |
| `typing_cpm` | `150` | 打字速度，字/分钟 |
| `voice_cpm` | `420` | 长句等效语音输入速度 |
| `think_seconds` | `3.0` | 思考等待，模型耗时计入其中 |
| `gate_timeout_seconds` | `45` | 单次判定超时 |
| `reply_timeout_seconds` | `240` | 人格回复含工具调用超时 |

判定遇到网络抖动重试一次，其他错误当轮沉默；图片预先转码缩放，GIF 取首帧。
pi 超时会连同派生工具进程终止。工具中的 `bash` 可执行本机命令；不需要时可从白名单移除。
